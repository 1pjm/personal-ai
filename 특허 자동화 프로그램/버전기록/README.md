# 버전 기록

무엇이 언제 왜 바뀌었는지 여기에 적는다. 코드를 뒤지지 아니하고도 알 수 있게 한다.

| 파일 | 무엇 |
| --- | --- |
| `변경내역.md` | 판별 기록. 최신이 맨 위 |
| `README.md` | 이 글. 어떻게 적는가 |

## 판 번호를 매기는 법

`큰수.가운데수.잔수` 로 적는다.

| 자리 | 언제 올리나 | 보기 |
| --- | --- | --- |
| **큰수** | 쓰는 법이 달라진다. 옛 자료를 그대로 못 쓴다 | 자체 킷 → 팀원 킷 2.7.0 으로 갈아탐 |
| **가운데수** | 하는 일이 늘어난다. 옛 자료는 그대로 쓴다 | 진행 상황 추적 마당이 생김 |
| **잔수** | 탈을 고치거나 다듬는다 | 요약 띠가 글을 가리던 것을 고침 |

## 무엇을 적나

한 판마다 아래를 적는다. **무엇을 했는가보다 왜 했는가와 무엇을 확인했는가가 중요하다.**
나중에 되짚을 때 궁금한 것은 늘 그 둘이다.

```markdown
## 2.1.0 — 2026-09-01

한 줄로 이 판이 무엇인지.

### 더한 것
- 무엇을 · 왜 필요했는지

### 고친 것
- 어떤 탈이 · 왜 났는지 · 어떻게 막았는지

### 걷어낸 것
- 무엇을 · 무엇으로 갈음하였는지

### 실측
- 눈으로 본 것이 아니라 실제로 재어 본 값

### 넘어간 것
- 하려다 아니한 것과 그 까닭
```

## 언제 적나

**고친 것을 밀어 넣기 전에 적는다.** 나중에 몰아 적으면 왜 그랬는지를 잊는다.

잔수 하나짜리 고침도 적는다. 「요약 띠가 글을 가렸다」 같은 것이 뒤에 다시 나기 쉽다.

## 판을 올린 뒤

1. `변경내역.md` 맨 위에 새 판을 적는다
2. `도구/출원도우미_N.N/` 폴더 이름의 판을 올린다. 옛 폴더는 `보관/구버전/` 으로
3. 전달용 묶음을 다시 만든다 — `python 도구/전달묶음_만들기.py`
4. 밀어 넣는다
