# 특허 자동화 프로그램

명세서를 쓰고 → 검사하고 → 관청에 낼 서류를 뽑는 일을 다룬다.

## 어디에 무엇이 있나

```
원고/                      ← 일하는 곳. 출원건 4건
도구/                      ← 지금 쓰는 것만 둔다
참고자료/                  ← 강사지침과 가이드
산출물/                    ← 뽑아낸 결과물 (날짜별)
보관/                      ← 지난 것. 지우지 아니하고 여기 둔다
```

## 쓰는 법 — 단추 하나

```
도구\출원 준비.bat
```

두 번 누르면 **브라우저 창이 열린다.** 특허를 하나도 몰라도 위에서부터 따라가면 된다.

| 마당 | 하는 일 |
| --- | --- |
| 0 | 어느 특허를 낼지 고른다. **폴더를 바꿔 다른 원고도 불러온다** (찾아보기 · 최근 목록) |
| 1 | 준비물 — 특허고객번호·전자문서 이용신고·인증서 (처음 한 번만) |
| 2 | 원고 검사 — 관청이 문제 삼을 곳을 쉬운 말로. 빠진 값은 화면에서 바로 채운다 |
| 3 | 서류 만들기 — 제출본·도면·DOCX·출원 준비서 |
| 4 | 비용 — 수수료를 셈해 보인다 |
| 5 | 특허로에 내기 — 차례와 링크, 서식에 적을 값 |
| 6 | 낸 뒤 — **출원번호를 넣으면 관청 기록을 불러** 지금 상태와 남은 기한(30일·1년·3년)을 셈한다 |

원고를 깊이 손보는 일(청구항 대비·선행기술·후보 원장)은 **특허킷 2.7.0 메인보드**가 낫다.
안내 화면이 그 보드를 함께 띄우고 2마당에서 이어 준다.

명령줄로 쓰려면:

```bash
python -m patentkit status 원고            # 4건 상태를 한 표로
python -m patentkit validate 원고/출원건_01_반증등급
python 도구/출원도우미_1.0/출원도우미.py 준비 원고
```

## 도구 — 무엇을 쓰고 무엇을 쓰지 아니하나

| 도구 | 판 | 자리 | 하는 일 |
| --- | --- | --- | --- |
| **특허킷** | **2.7.0** | `도구/특허킷_2.7.0/` | 원고를 보고 서류를 뽑는다. **현행** |
| **출원도우미** | **1.0** | `도구/출원도우미_1.0/` | 수수료·사전등록·제출 차례. **현행** |
| ~~특허자동화킷~~ | ~~1.0~~ | `보관/구버전/` | 2.7.0 으로 갈음하였다. **쓰지 아니한다** |

**특허킷 2.7.0** 은 팀원이 만든 것이다. 우리가 만들던 1.0 보다 모든 면에서 낫다
(8,672줄 29모듈 · 명령 23개 · 자체시험 131개). 1.0 이 놓치던 깨진 SVG 도 잡는다.
그래서 1.0 은 손대지 아니하고 `보관/구버전/` 에 두었다.

설치는 `도구/특허킷_2.7.0/원본/설치.bat` 을 두 번 누르면 된다. 파이썬이 없어도 알아서 깐다.

## KIPRIS 열쇠

6마당의 진행 상황 추적은 KIPRIS 열쇠가 있어야 돈다.
[plus.kipris.or.kr](https://plus.kipris.or.kr) 에서 받아 화면에 한 번 넣으면 계속 쓴다.

열쇠는 `~/.patentkit-helper.json` 에 둔다. **`patent_config.json` 에 넣지 아니한다.**
그 파일은 배포 묶음에 실려 사외로 나가기 때문이다. 집 폴더의 적바림은 어디로도
따라가지 아니한다.

## 버전을 붙이는 규칙

앞으로 섞이지 아니하도록 이렇게 한다.

1. **도구 폴더 이름에 판을 적는다** — `출원도우미_1.0`, `특허킷_2.7.0`.
   판이 올라가면 새 폴더를 만들고, 옛 폴더는 `보관/구버전/` 으로 옮긴다. **덮어쓰지 아니한다.**
2. **`도구/` 에는 현행만 둔다.** 여기 있는 것은 지금 쓰는 것이라는 뜻이다.
3. **산출물은 날짜를 앞에 붙인다** — `20260826_시험서류`. 언제 뽑은 것인지가 먼저다.
4. **보관은 지우지 아니한다.** 되돌아볼 일이 생긴다.

## 조심할 것

**`원고/`·`산출물/`·`보관/원본자료/` 는 git 에 올리지 아니한다.**
출원 전 명세서 전문이 들어 있고, 공개되면 신규성에 영향을 줄 수 있다(특허법 제29조).
`.gitignore` 에 막아 두었으나, 새 폴더를 만들 때 다시 확인한다.

**관청 제출은 사람이 누른다.** 특허청은 제출용 공개 API 를 두고 있지 아니하며,
제출은 공동인증서로 서명하는 법률행위다(특허법 제28조의3, 시행규칙 제9조의6).
도구는 그 직전까지 만든다.
