# 특허 출원 도우미 — 기능 문서

판 2.0.1 · 2026-08-30 기준

이 글 하나로 「무엇을 하는 프로그램이고, 누구를 위한 것이며, 어디까지 되고 어디서 막히는지」
를 알 수 있게 적는다.

---

## 1. 한 줄로

**특허를 한 번도 내 본 적 없는 사람이, 화면을 따라가기만 하면 관청에 낼 서류를 갖추게 하는
프로그램이다.** 마지막 「제출」 단추만 사람이 누른다.

프로그램은 두 개다. 하나만 써도 되고, 필요하면 다른 하나로 건너간다.

| | 특허 출원 안내 | 전문가용 메인보드 |
| --- | --- | --- |
| **무엇** | 출원 절차를 끝까지 끌고 가는 안내 화면 | 원고를 깊이 손보는 작업대 |
| **누구** | 특허를 모르는 사람 | 명세서를 직접 쓰고 고치는 사람 |
| **판** | 출원 도우미 1.0 (우리가 만듦) | 특허킷 2.7.0 (팀원이 만듦) |
| **언제** | 늘 여기서 시작한다 | 안내 화면이 「고쳐야 한다」 할 때 |

둘은 `출원 준비.bat` 하나로 **함께 뜬다.** 안내 화면 표제 오른쪽 「전문가용 메인보드」 로
언제든 건너간다.

---

## 2. 누구를 위한 것인가

### 주 대상 — 특허를 처음 내는 사람

변리사를 쓰지 않고 **가출원(임시명세서)** 을 직접 내려는 개인·소규모 기업을 전제한다.
「출원인코드가 뭐죠」 수준을 가정하고 만들었다.

그래서 이렇게 한다.

- 관청 말투를 걷어낸다 — 「[오류] 미확정 — inventors[0].name」 대신
  「사람이 정해야 하는 값이 비어 있습니다」
- 무엇을 눌러야 하는지 화면에 적는다. 스스로 다음 칸을 찾게 하지 아니한다
- 왜 필요한지 함께 적는다 — 「발명자를 빠뜨리면 등록된 뒤에도 무효가 될 수 있습니다」
- 근거 조문을 옆에 둔다. 못 미더우면 확인할 수 있게

### 곁 대상 — 명세서를 직접 쓰는 사람

메인보드가 그쪽이다. 청구항 대비, 단락번호 다시 매기기, 선행기술 조사, 구현 대조까지 다룬다.

### 대상이 아닌 사람

- **변리사에게 맡긴 사람** — 할 일이 없다
- **해외 출원을 하려는 사람** — 한국 특허청(KIPO)만 다룬다. PCT·미국·유럽은 아니 한다
- **상표·디자인을 내려는 사람** — 특허와 실용신안만 본다

## 3. 지금 되는 일

### 특허 출원 안내 — 일곱 마당

| 마당 | 하는 일 | 자동인가 |
| --- | --- | --- |
| **0** 어느 특허를 낼까요 | 원고 폴더를 고른다. 찾아보기·최근 목록. 폴더 아래 몇 단계든 찾아낸다 | 자동 |
| **1** 준비물 갖추기 | 특허고객번호·전자문서 이용신고·인증서가 되었는지 본다. 각각 신청하는 자리로 이어 준다 | **확인만**. 신청은 사람이 |
| **2** 원고 검사 | 관청이 문제 삼을 곳을 찾아 쉬운 말로 알린다. 사람이 정해야 하는 값은 화면에서 바로 채운다 | 자동 |
| **3** 서류 만들기 | 제출본·도면 PNG·워드 파일(DOCX)·출원 준비서를 만든다 | 자동 |
| **4** 비용 확인 | 출원료를 셈한다. 심사청구료도 미리 알린다 | 자동 |
| **5** 특허로에 내기 | 내는 차례 일곱 걸음과 서식에 옮겨 적을 값. 한꺼번에 복사 | **안내만**. 제출은 사람이 |
| **6** 낸 뒤 진행 상황 | 출원번호로 관청 기록을 불러 지금 상태와 남은 기한을 셈한다 | 자동 |

#### 수수료 계산 (4마당)

```
기본 출원료   46,000원   전자출원·국어 (서면 66,000 · 외국어 73,000)
면수 가산     20면을 넘는 1면마다 1,000원
감면          개인·중소기업 70% · 학생 100%
──────────────────────────────────
심사청구료    166,000원 + 청구항당 51,000원   ← 따로. 출원일부터 3년 안에
```

감면율은 설정의 글월에서 읽는다. **못 읽으면 감면하지 아니한다** — 적게 잡는 편이 낫다.
면수는 제출본 글자수(1면 ≈ 1,000자)에 도면 장수를 더해 **어림한다.** 정확한 금액은 특허로
결제 화면이 정본이다.

#### 기한 셈 (6마당)

출원일에서 세어 셋을 보인다. 지난 것은 붉게, 30일 안에 든 것은 노랗게.

| 기한 | 무엇 | 근거 |
| --- | --- | --- |
| 30일 | 공지예외 증명서류 | 특허법 제30조제2항 |
| 1년 | 정식 명세서로 바꾸기 | 특허법 제42조의2제2항 |
| 3년 | 심사청구 | 특허법 제59조제2항 |

### 전문가용 메인보드 — 특허킷 2.7.0

8,672줄 29모듈. 명령 23개. 자체 시험 131개.

## 4. 밖에 이어진 것

### 프로그램이 실제로 부르는 것

| 어디 | 무엇에 | 열쇠 | 없으면 |
| --- | --- | --- | --- |
| **KIPRIS Plus** `getBibliographyDetailInfoSearch` | 출원번호 → 서지상세·법적상태·청구항 (6마당 추적, 메인보드 선행기술) | 필요 | 6마당만 못 쓴다. 나머지는 그대로 |
| **임의의 웹 주소** | 공개 증거 수집 (메인보드 `evidence`) | 없음 | 그 명령만 못 쓴다 |

**그 밖에는 밖으로 나가지 아니한다.** 원고는 이 컴퓨터를 떠나지 않는다.
안내 화면 코드에는 바깥으로 나가는 호출이 하나도 없다 — 관청 주소는 브라우저로 여는
**링크일 뿐**이다.

### 화면이 이어 주는 관청 자리 (링크)

| --- | --- |

### 딸린 것

| 무엇 | 어디에 쓰나 | 없으면 |
| --- | --- | --- |
| 파이썬 3.10+ | 프로그램 자체 | 돌지 아니한다 |
| `patentkit` 2.7.0 | 검사·제출본·서식 | 처음 켤 때 알아서 깐다 |
| `python-docx` | 워드 파일 | DOCX 만 못 만든다 |
| 엣지 또는 크롬 | 도면 PNG | 도면 렌더만 못 한다 |
| KIPRIS 열쇠 | 6마당 추적 | 6마당만 못 쓴다 |

### 열쇠를 어디에 두나

`~/.patentkit-helper.json` — **그 컴퓨터의 개인 폴더**에 둔다.
`patent_config.json` 에 넣지 아니한다. 그 파일은 전달 묶음에 실려 사외로 나가기 때문이다.

## 5. 한계 — 안 되는 것과 그 까닭

### ① 관청에 대신 내 주지 못한다 (가장 큰 한계)

**「단추 한 번으로 출원까지」 는 만들 수 없다.** 두 가지가 막는다.

**제출용 API 가 없다.** 특허청이 내놓은 열린 API 는 KIPRIS·공공데이터포털의 **조회용뿐**이다.
넣는 통로는 공개돼 있지 않다.

**제출이 법률행위다.** 공동인증서로 서명해야 한다(특허법 제28조의3, 시행규칙 제9조의6).
프로그램이 사용자의 인증서를 대신 다루는 것은 기술로도 어렵고 마땅하지도 않다. 출원일이
확정되고 수수료가 결제되며, 가출원은 **낸 뒤 새 내용을 더할 수 없다.**

그래서 **5마당의 「제출」과 「결제」 두 칸만** 사람에게 남기고 그 앞뒤를 모두 만든다.
팀원의 2.7.0 에도 이 기능은 없다. 만들 수 없어서다.

### ② `.HLZ` 를 직접 만들지 못한다

관청이 받는 형식이 `.HLZ` 인데 그 명세가 공개돼 있지 않다. 짐작으로 만들면 관청이 받지
아니하는 파일이 나온다. **NK-Editor 로 워드 파일을 바꾸는 한 걸음은 사람이 한다.**

### ③ 판단하지 아니하고 형식만 본다

| 안 하는 일 | 왜 |
| --- | --- |
| 선행기술 저촉 판단 | 자료는 모아 주지만 「이게 걸린다」 는 사람이 정한다 |
| 청구범위 권리 설계 | 문언의 형식 정합만 본다. 얼마나 넓게 받을지는 사람의 몫 |
| 등록될지 여부 | 알 수 없다. 심사관이 정한다 |
| 공지예외 증명서류 작성 | 기한만 알린다 |

**이 프로그램은 법률 자문이 아니다.** 실제 출원 전에는 변리사 검토를 권한다.

### ④ 사람이 채워야 막히지 않는 값

`patent_config.json` 의 `★` 는 프로그램이 풀 수 없는 값이다. 채우기 전에는 서식이 나오지
않는다. 보통 둘이다 — **발명자 성명**, **사업자등록번호**.

발명자는 화면 2마당에서 바로 채울 수 있으나, **누구인지 정하는 것은 사람의 일이다.**
퇴사자와 사외 공동발명자를 빠뜨리면 등록된 뒤에도 무효사유가 된다. 「홍길동」 같은 예시
이름은 프로그램이 막는다.

### ⑤ 어림하는 값

- **수수료 면수** — 글자수로 어림한다. 정확한 금액은 결제 화면이 정본
- **수수료 요율** — 2026-08-28 에 확인한 값이다. 규칙이 개정되면 어긋난다

### ⑥ 다루는 범위

- **한국 특허청만.** PCT·해외 출원은 아니 한다
- **특허·실용신안만.** 상표·디자인은 메인보드의 KIPRIS 검색으로 조회만 된다
- **가출원(임시명세서) 중심.** 정식 출원도 되지만 안내는 가출원을 전제한다
- **윈도우만 시험하였다.** 코드는 다른 데서도 돌 만하나 확인하지 아니하였다

### ⑦ 메인보드 쪽

**팀원이 만든 것이라 우리가 고치지 아니한다.** 색만 우리 화면에 맞춰 두었다
(`도구/메인보드_옷.py`). 팀원이 2.8.0 을 내면 그 옷은 사라지므로 한 번 더 입혀야 한다.

메인보드 자체는 초보자를 위해 만들어지지 않았다. 「청구항 대비」·「확대된 선원」 같은 말이
설명 없이 나온다. 그래서 안내 화면을 앞에 세웠다.

## 6. 쓰기 시작하려면

```
도구\출원 준비.bat        ← 두 번 누른다
```

브라우저 창 두 개가 열린다. **특허 출원 안내**만 따라가면 된다.

처음 쓰는 사람이 걸리는 자리는 대개 셋이다.

1. **파이썬이 없다** — [python.org](https://www.python.org/downloads/) 에서 깔되
   첫 화면의 "Add python.exe to PATH" 를 켠다
2. **원고가 없다** — `patent_config.json` 이 든 폴더가 특허 하나다. 없으면 메인보드의
   `init` 으로 뼈대를 만든다
3. **1마당 준비물이 안 되어 있다** — 특허고객번호는 처음 한 번 신청해야 한다.
   며칠 걸릴 수 있으니 먼저 해 두는 편이 낫다
