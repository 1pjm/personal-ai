# 특허 자동화 킷 2.7.0 — 설치 안내

## 설치 (한 번만)

1. 이 폴더의 **설치.bat** 을 두 번 누른다.
2. 파이썬이 없으면 설치할지 물어본다. **Y** 를 누르면 알아서 깔린다.
3. 「설치를 마쳤다」가 나오면 아무 키나 눌러 닫는다.
4. 바탕화면에 생긴 **「특허 자동화 킷」** 아이콘을 두 번 누르면 시작한다.

관리자 권한이 필요 없다. 설치되는 곳은 `%LOCALAPPDATA%\Programs\PatentKit\` 이며,
회사 공용 폴더나 다른 프로그램에는 손대지 않는다.

## 쓰는 법

아이콘을 누르면 번호로 고르는 화면이 뜬다. **1번을 누르면 웹 메인보드가 열린다.**
브라우저 화면 하나에서 출원건 전체를 보고 모든 작업을 단추로 돌릴 수 있다.

```
  1. 웹 메인보드 열기            9. 단락번호 다시 매기기
  2. 출원건 현황 한눈에 보기    10. 선행기술 조사 결과 보기
  3. 새 출원건 폴더 만들기      11. 인용문헌 대비표 만들기
  4. 검사하기                   12. 공개 증거 받아 두기
  5. 제출본 만들기              13. 청구항·제품 소스 대조
  6. 도면 초안 만들기           14. 변리사 검토 초안·종합보고서
  7. 도면 그리기 (SVG → PNG)    15. 실행 환경 점검
  8. 관청 서식(DOCX) 만들기     16. 이 컴퓨터에 설치
  0. 나가기
```

### 웹 메인보드

메인보드는 **이 컴퓨터에서만** 열린다(127.0.0.1). 열 때마다 새 열쇠를 붙인 주소를
쓰므로 같은 망의 다른 사람은 열지 못한다. 창을 닫으면 화면도 닫힌다.

  · 왼쪽 — 출원건 목록. 오류 개수와 준비 눈금이 보인다
  · 가운데 — 검사·제출본·도면·조사·대비·대조·보고서·서식을 단추 하나로
  · 아래 — 실행 기록이 실시간으로 쌓인다
  · 발명 후보 원장 — 등급은 사람이 매기고, 킷은 등급을 매길 근거만 세어 보인다

출원건 폴더는 바탕화면과 그 아래에서 자동으로 찾는다. 못 찾으면 물어보는데,
그때는 탐색기에서 폴더를 창으로 끌어다 놓고 Enter 를 누르면 된다.

명령줄이 익숙하면 아무 창에서나 `특허킷 validate 출원건_01` 처럼 쓸 수 있다.
(설치한 뒤 새로 연 창부터 된다.)

## 제거

**제거.bat** 을 두 번 누른다. 바탕화면 아이콘·시작 메뉴·PATH·프로그램 파일이
모두 원래대로 돌아간다. **출원건 자료는 그대로 남는다.**

## 잘 안 될 때

- 무엇이 되고 무엇이 안 되는지는 프로그램의 **13. 실행 환경 점검** 이 알려 준다.
- 관청 서식(DOCX)과 도면 렌더까지 모두 「됨」으로 나와야 정상이다.
  도면은 마이크로소프트 엣지를 쓰므로 따로 설치할 것이 없다.
- 자세한 설명서는 함께 든 `README.md` 에 있다.
