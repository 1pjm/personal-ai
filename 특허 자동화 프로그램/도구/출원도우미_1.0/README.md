# 출원 도우미

명세서가 다 되었을 때부터 관청에 내기까지를 한 번에 끌고 간다.
원고를 보는 일은 **특허 자동화 킷(patentkit 2.7.0)** 이 하고, 그 뒤를 이 도우미가 본다.

```bash
python 출원도우미.py 준비 <출원건폴더|상위폴더>   # 단추 하나로 여기까지
python 출원도우미.py 추적 1020260142020          # 출원 뒤 진행 상황
```

창 없이 쓰려면 **「출원 준비.bat」** 을 두 번 누른다. 킷이 없으면 알아서 깐다.

## 「준비」 가 하는 일

1. 킷으로 **제출본 → 도면 → 검사 → 서식(DOCX)** 을 차례로 만든다
2. **수수료를 셈한다** — 기본 + 면수 가산 − 감면
3. **사전등록 3가지**가 되었는지 설정에서 확인한다
4. `_출력/출원_준비.md` 로 특허로에 옮겨 적을 값과 제출 차례를 뽑는다

## 수수료

출처: [특허로 수수료정보안내](https://www.patent.go.kr/smart/jsp/ka/menu/fee/main/FeeMain01.do) (2026-08-28 확인)

| 항목 | 금액 |
| --- | --- |
| 전자출원 국어 | 46,000원 |
| 전자출원 외국어 | 73,000원 |
| 면수 가산 | 20면 초과 1면마다 1,000원 |
| 심사청구료 | 166,000원 + 청구항당 51,000원 |
| 감면 | 개인·중소기업 70% · 학생 100% |

감면율은 `patent_config.json` 의 `filing.fee_reduction` 글월에서 읽는다. 「중소기업 70%」
처럼 퍼센트가 있으면 그것을, 없으면 「개인」·「학생」 같은 말을 본다. **못 읽으면 감면하지
아니한다** — 적게 잡아 두는 편이 낫다.

면수는 제출본 글자수(1면 ≈ 1,000자)에 도면 장수를 더해 어림한다. 정확한 금액은 결제
직전 화면이 정본이다.

## 사전등록 — 처음 한 번만

| 할 일 | 설정 자리 | 근거 |
| --- | --- | --- |
| 특허고객번호(출원인코드) 부여신청 | `applicants[0].customer_no` | 특허법 제28조의2제1항 |
| 전자문서 이용신고 | `filing.edoc_reported` | 특허법 제28조의4제1항 |
| 인증서 발급 및 사용등록 | `filing.cert_registered` | 시행규칙 제9조의6 |

값을 채워 두면 다음부터 「완료」 로 뜬다.

## 도우미가 하지 아니하는 일

**관청 제출을 대신 누르지 아니한다.**

특허청은 제출용 공개 API 를 두고 있지 아니하다. 공개된 것은 KIPRIS·공공데이터포털의
**조회용** API 뿐이다. 제출은 명세서를 NK-Editor 로 `.HLZ` 로 바꾸고 특허로에서
**공동인증서로 서명**하는 법률행위다(특허법 제28조의3, 시행규칙 제9조의6).

그래서 차례 7·8번(서명·결제)은 사람이 누른다. 그 앞의 1~6번과 뒤의 9·10번 안내를
이 도우미가 만든다.
